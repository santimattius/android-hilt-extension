[![Maven Central](https://img.shields.io/maven-central/v/com.santimattius.android/hilt-extension?color=blue&label=Maven%20Central)](https://central.sonatype.com/artifact/com.santimattius.android/hilt-extension)

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![CI](https://github.com/santimattius/android-hilt-extension/actions/workflows/ci.yml/badge.svg)](https://github.com/santimattius/android-hilt-extension/actions/workflows/ci.yml)

Runtime tracing for Hilt, plus coroutine helpers.

- **Hilt Trace** adds Perfetto trace sections around Hilt object creation and injection in debug builds, so a trace shows which bindings a startup creates, in what order and how long each takes.
- **Coroutine helpers** give Hilt apps dispatcher and scope qualifiers, suspending adapters for `Provider` and `Lazy`, and a trace section that follows a coroutine.

**Status: alpha (`1.0.0-alpha01`).** The four artifacts below are not published to Maven Central yet; the sample app resolves them from this repository. The badge above refers to the earlier `com.santimattius.android:hilt-extension` artifact, which is unrelated to this code.

## What it promises

| Promise | Scope |
|---------|-------|
| Sections for Hilt creation (`hilt.create`) and injection (`hilt.inject`) | Debug and `benchmark` variants of an application module, generated by bytecode transform of Hilt output. |
| Release builds are not instrumented | Release classes and dex stay byte-identical to a build without the plugin (checked by `ReleaseUnchangedTest`). |
| Nothing recorded when tracing is off | `HiltTrace.begin` returns `null` for a disabled category; no driver installed means disabled. |
| The build never fails because of the instrumentation | An unknown class shape or any error leaves the original bytes and logs one warning. |
| `SuspendLazy`, `Provider.suspending`, `Lazy.await`, `traceCoroutine` | Contracts for caching, failure and cancellation are covered by JVM tests. |

What it does **not** promise (not instrumented, no automatic scope cancellation, no measured overhead) is listed in [Limitations](docs/LIMITATIONS.md).

## Modules

All artifacts use the group `com.santimattius.android` and the version in `gradle.properties` (`libraryVersion`).

| Artifact | Kind | Purpose |
|----------|------|---------|
| `hilt-trace-gradle-plugin` | Gradle plugin, id `com.santimattius.android.hilt.trace` | Instruments the generated Hilt classes of selected variants. |
| `hilt-trace-compiler` | KSP processor | Writes the binding catalogue `META-INF/hilt-trace/<module>.json`. |
| `hilt-trace-runtime` | Android library | `HiltTrace` facade over `androidx.tracing` 2.0.5. Called by instrumented code. |
| `hilt-coroutines-runtime` | Android library | Dispatcher and scope qualifiers, `SuspendProvider`, `SuspendLazy`, `Lazy.await`, `traceCoroutine`. |

Also in this repository: `:app` (sample and validation harness, not published) and `build-logic/` (convention plugins, not published).

## Quick start

In an application module that already uses Hilt with KSP:

```kotlin
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.ksp)
    alias(libs.plugins.hilt)
    id("com.santimattius.android.hilt.trace")
}

ksp {
    arg("hiltTrace.module", ":app")
}

dependencies {
    implementation(libs.hilt.android)
    ksp(libs.hilt.compiler)
    implementation(libs.androidx.tracing)
    debugImplementation(libs.androidx.tracing.wire)   // records traces; optional
    implementation(project(":hilt-coroutines-runtime")) // optional: coroutine helpers
}
```

Then build and run a debug variant and record a trace. Everything else (library modules, versions, publishing state) is in the guides below.

## Build and test

```bash
./gradlew :app:testDebugUnitTest        # sample unit tests
./gradlew :app:assembleDebug            # build the sample
./gradlew check                         # every module, included builds and version alignment
./gradlew :app:connectedDebugAndroidTest  # needs a device or emulator (CI only compiles them)
```
